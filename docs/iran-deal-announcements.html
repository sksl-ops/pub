04 / HOW TO READ THIS COUNT

数え方と、この数字の限界

何を1件として数えたか

  • 別々の会見・取材・投稿などの発信機会を単位にしています。交渉ラウンドや合意案の数ではありません。
  • 「合意間近」に加え、イランが合意・会談を切望、懇願しているとの主張を含めています。
  • 同じ発言の転載、同じ取材の収録日と放送日、記事更新を別件にはしていません。
  • 本人の発言記事を「本人1回＋ニュース1件」と二重加算していません。

何が未確定か

  • 既存のCNN38回は、全件をこちらで独自に再集計したものではありません。掲載例には「終戦が近い」も含まれます。
  • 追加8回と別系列7件は確認できた分で、期間内の全発言・全記事を網羅していません。
  • 追加本人発言が9月16日までなのは、それ以降に同種発言が存在しないという意味ではありません。
  • 発言・報道の存在を数えたもので、イランが実際に懇願した、合意が本当に目前だった、と認定する調査ではありません。

結論：広義で、少なくとも53件

「合意間近／イランが合意・会談を懇願」という一連の発信は、CNN既存集計を土台にすると本人46回以上、別系列の報道7件以上、計53件以上です。ただし期間中には合意成立後の再交渉もあり、「同じ未成立の合意を53回予告した」「53回とも失敗した」ことを意味しません。
